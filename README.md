## A. Problem Statement

The objective is to develop, evaluate, compare, and deploy five supervised classification algorithms on the **same public classification dataset**. The experiment includes data preparation, a reproducible training/test split, model fitting, evaluation with six prescribed metrics, saving trained models, and an interactive Streamlit frontend.

The deployed app allows users to upload a labeled **test CSV**, choose any of the five classifiers, and inspect evaluation metrics, a confusion matrix, a classification report, and a comparison across all five models. The app **loads previously trained models** and does **not retrain** them on uploaded test data.

## B. Dataset Description

**Dataset:** Breast Cancer Wisconsin (Diagnostic) (WDBC)  
**Original source:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast-cancer-wisconsin-diagnostic)  
**Loading method:** `sklearn.datasets.load_breast_cancer()` (the scikit-learn bundled version of the UCI dataset)

| Attribute | Description |
|---|---|
| Problem type | Binary classification |
| Total instances | 569 |
| Number of input features | 30 numerical features |
| Target classes | 0 = malignant, 1 = benign |
| Missing values | None in the bundled dataset |
| Training portion | 455 samples (80%) |
| Held-out test portion | 114 samples (20%) |
| Splitting method | `train_test_split(test_size=0.2, random_state=42, stratify=y)` |

The features summarize characteristics of cell nuclei in digitized images, including radius, texture, perimeter, area, smoothness, compactness, concavity, symmetry, and related measures. The dataset meets the assignment's minimum of **500 instances and 12 features**.

**Preprocessing:** A `StandardScaler` is fitted only on training data and applied to Logistic Regression, KNN, and SVM. Decision Tree and Gaussian Naive Bayes use unscaled features. The fitted scaler is saved alongside the model artifacts. This avoids test-set leakage during preprocessing.

**Metric convention:** The binary evaluation uses the dataset's positive class **1 = benign** for Precision, Recall, F1, and AUC. These scores should not be interpreted as malignant-class recall. The project is an educational model-comparison exercise, **not a medical diagnostic tool**.

## D. Models Used and Evaluation Metrics

All five models are trained on the same training partition and tested on the same held-out partition. The six prescribed metrics are Accuracy, Area Under the ROC Curve (AUC), Precision, Recall, F1 Score, and Matthews Correlation Coefficient (MCC).

**Evaluation results** (from the enhanced project's `metrics.csv`, rounded to four decimal places):

| ML Model Name | Accuracy | AUC | Precision | Recall | F1 | MCC |
|---|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.9825 | **0.9954** | 0.9861 | 0.9861 | 0.9861 | 0.9623 |
| Decision Tree | 0.9123 | 0.9157 | 0.9559 | 0.9028 | 0.9286 | 0.8174 |
| KNN | 0.9561 | 0.9788 | 0.9589 | 0.9722 | 0.9655 | 0.9054 |
| Gaussian Naive Bayes | 0.9386 | 0.9878 | 0.9452 | 0.9583 | 0.9517 | 0.8676 |
| Support Vector Machine | **0.9825** | 0.9950 | **0.9861** | **0.9861** | **0.9861** | **0.9623** |

**Evaluation definitions:**

- **Accuracy:** Proportion of correctly classified instances.
- **AUC:** Area under the Receiver Operating Characteristic curve, computed from positive-class predicted probabilities.
- **Precision:** Of samples predicted positive, fraction truly positive.
- **Recall:** Of actual positive samples, fraction correctly predicted positive.
- **F1 Score:** Harmonic mean of Precision and Recall.
- **MCC:** A balanced correlation-based measure based on all four confusion-matrix cells, ranging from -1 to +1.

## E. Observations on Model Performance

| ML Model Name | Observation about model performance |
|---|---|
| **Logistic Regression** | Achieves 98.25% Accuracy, 0.9861 F1, and the **highest AUC (0.9954)**. Standardized features help the linear model, suggesting the classes are well separated by a relatively simple decision boundary on this split. |
| **Decision Tree** | Has the lowest Accuracy (91.23%), F1 (0.9286), and MCC (0.8174) of the five candidates. A single unrestricted tree can be sensitive to the particular training sample and may generalize less reliably than the other fitted models here. This experiment alone does not prove overfitting; training-versus-test analysis would be needed. |
| **K-Nearest Neighbors** | Delivers 95.61% Accuracy, 0.9655 F1, and 0.9722 Recall. Performance is strong after scaling, although slightly below Logistic Regression and SVM on this test set. |
| **Gaussian Naive Bayes** | Achieves 93.86% Accuracy and high AUC (0.9878). Its independence and Gaussian feature assumptions make it computationally simple but may limit its prediction quality when features are correlated. |
| **Support Vector Machine (RBF)** | Ties Logistic Regression for the highest Accuracy (98.25%), Precision (0.9861), Recall (0.9861), F1 (0.9861), and MCC (0.9623). Its AUC (0.9950) is slightly below Logistic Regression. |
| **Overall winner for this dataset** | **Logistic Regression (narrow selection)** because it ties with SVM on the five threshold-based metrics and leads marginally on AUC (0.9954 vs. 0.9950). **SVM is an equally strong choice** if selecting by Accuracy, F1, or MCC alone. These results describe this fixed test split, not universal superiority. |

## F. Streamlit Application Features

The app provides:

1. **Test CSV upload:** Upload a CSV with the 30 required input features and `target` column.
2. **Model-selection dropdown:** Choose Logistic Regression, Decision Tree, KNN, Gaussian Naive Bayes, or SVM.
3. **Evaluation dashboard:** Display Accuracy, AUC, Precision, Recall, F1 and MCC for uploaded test data.
4. **Confusion matrix and classification report:** Inspect per-class outcomes and supporting metrics.
5. **All-model comparison:** Compare the five saved classifiers on the **currently uploaded CSV**. The saved training-run metrics table, if shown, is clearly labeled as a reference and should not be confused with uploaded-data results.
6. **Prediction-only inference:** Models and scaler are loaded from saved `.pkl` files; the uploaded dataset is never used to fit or retrain a model.
